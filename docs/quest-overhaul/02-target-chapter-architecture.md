# Target chapter architecture

The objective is to keep the strongest source-pack structure while giving FPBCraft additions a natural home. This is a proposed information architecture, not an instruction to rewrite every chapter.

## Ungrouped onboarding

### Tutorial
Preserve the useful All of Create Aeronautics tutorial layout. Cover quest-book usage and pack-level conventions.

### Getting Started
Keep only a small early-game progression if it is still useful after redistribution. Do **not** use this as the default home for one-off mod introductions.

## Create

Preserve the source progression as much as possible:

- Getting Started (Create-specific)
- Copper Age
- Andesite Age
- Brass Age
- Locomotive Age

Restore source quests for currently installed addons when they fit these existing layouts, especially Mobile Packages and `create: things and misc` train content.

## Aeronautics

Keep existing Aeronautics / Simulated / Propulsion / Off-Road pages and integrate the current Flight Workshop material.

Proposed pages/branches:

- Aeronautics core
- Simulated / vehicle construction
- Propulsion
- Off-Road
- **Aeronautics Toolgun** — expanded substantially
- Aeroworks controls
- Throwable Rope Connector / climbing utilities
- optional compact page for other Aeronautics-specific QoL addons

## Engineer's Paradise

This becomes the common home for industrial Create addons and **all electricity-related pages**, avoiding the current duplicate Create/electricity group.

Proposed pages:

- Create: Connected
- Create: Enchantment Industry
- Pump Dat Oil / Diesel Generators
- Create: Aquatic Ambitions
- Fun Additions
- Create: Optical
- Create: Blaze Burner Fuels
- Create Ore Excavation
- Create Big Cannons
- **Create Nuclear**
- **Electricity fundamentals / Create Crafts & Additions**
- **Create: Electro Energetics** (restore the strong AOC source chapter)
- **Create: Power Grid**

Cross-link electricity pages instead of duplicating the same motor/alternator/wire concepts.

## Transportation

- Trains
- Minecarts
- **Railway Services** (Railways Navigator and useful train addons)
- **Create: Power Loader**
- train-parts / station utilities where they are not already handled cleanly by Trains

Power Loader belongs here because its important use is keeping ground, train and contraption chunks loaded.

## Farming & Food

This needs multiple pages rather than one kitchen sampler:

- **Farmer's Delight** — crop-to-meal progression
- **Create Kitchen** — retain source layout and restore compatible source quests
- **Immortalers Delight** — ancient crops / Sniffer archaeology / processing / foods
- Cooking for Blockheads
- Create: Slice & Dice / Integrated Farming integrations
- **Tide Fishing** — fishing gear, journal and progression (can cross-link Adventure & Exploration)
- Delight addons: Chef's Delight, Crabber's Delight, Crate Delight, Miner's Delight, End's Delight, My Nether's Delight, Ocean's Delight, Rustic Delight, Storage Delight where they provide enough meaningful gameplay for a branch

## Storage & Logistics

- Sophisticated Backpacks
- **Tom's Simple Storage** — full progression, not just three terminals
- Create Contraption Terminals integration
- CC:Tweaked / Advanced Peripherals / CC:C Bridge can remain here initially, or split to a Computers page if coverage grows

## Building & Decoration

A new first-class home for building-focused mods avoids scattering one-off quests through Getting Started.

- **Supplementaries** — dedicated chapter
- **Furniture** — one clear onboarding quest/mini-branch for Another Furniture, Handcrafted and Immersive Furniture
- **Macaw's Building** — one branch per installed Macaw module (Bridges, Doors, Fences & Walls, Paintings, Roofs, Stairs & Balconies, Trapdoors, Windows; Macaw's Quark integration as relevant)
- Additional Lights
- Redden's Stone Lanterns
- MultiBeds
- Amendments / other small decor mods only when they teach a non-obvious mechanic

## Adventure & Exploration

- **Archaeology** — Better Archeology as a dedicated page; link Immortalers Delight archaeology where appropriate
- **Aquamirae** — Ship Graveyard progression, gear and bosses
- **Galosphere** — underground biomes/resources/mobs/tools/Echo Altar
- **Naturalist** — emphasize its useful tools/equipment and animal interactions rather than demanding every animal
- **Myths of the Sea** — creatures/boss encounters if boss coverage warrants a dedicated branch
- **Hang Glider**
- **Grappling Hook**
- Exposure photography
- exploration utilities (Nature's Compass / Explorer's Compass / Waystones) where useful

## Tools & Equipment / Combat

Whether this is its own group or folded into Adventure/RPG is still open. Candidates:

- **Just Hammers**
- **Immersive Armors**
- Simply Swords (move out of a misleading Collectibles group unless the rare weapon collection remains the intended design)
- Traveler Tool Belt
- other compact equipment mods with mechanics worth teaching

## RPG Series

Create a dedicated top-level group. See `03-mod-coverage-plan.md` for the detailed tree.

## Bosses

Create a dedicated top-level group or a prominent Adventure subgroup. Use Boss Checklist as the encyclopedia and FTB Quests as the guided progression/reward layer.

Likely sources:

- Legendary Monsters
- Mowzie's Mobs
- Aquamirae
- Myths of the Sea
- Ender Dragon Fight Remastered
- vanilla Wither / Ender Dragon where they are important prerequisites
- any additional bosses detected by Boss Checklist once the exact runtime mod set is available
